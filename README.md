# Adidas US Interactive Sales Dashboard

## Overview
This repository showcases an **Adidas US Interactive Sales Dashboard**, a Business Intelligence solution designed to analyze and visualize sales performance metrics. This dashboard provides a comprehensive view of revenue, profitability, and distribution channels to support data-driven decision-making.

## 📊 Dashboard Features

### Key Performance Indicators (KPIs)
The dashboard provides an immediate snapshot of top-level metrics:
* **Units Sold:** 2,478,861 total units.
* **Profit:** $332,134,761.45 total profit.
* **Retailer Coverage:** Analysis across 6 major retail partners.

### Interactive Filters
The dashboard features an interactive sidebar that allows users to filter data dynamically:
* **City Filter:** Narrow down performance by specific cities (e.g., Albany, Albuquerque).
* **State Filter:** Segment data by state to analyze regional performance variations.

### Data Visualizations
The dashboard includes the following insights:

1. **Profit Per Product (Bar Chart):** Compares the profitability of Men's and Women's categories (Apparel, Athletic Footwear, and Street Footwear).
2. **Sales Method (Pie Chart):** Breaks down revenue sources by channel (In-store, Online, and Outlet).
3. **Total Sales by Retailer (Horizontal Bar Chart):** Ranks retail partners (e.g., West Gear, Foot Locker, Sports Direct) by their contribution to total revenue.
4. **Sales Trend by Quarters (Line Chart):** Illustrates revenue growth patterns across 2020 and 2021, highlighting the year-over-year performance trajectory.
5. **Sales Region (Geo Map):** Provides a geographic visualization of sales concentration across the United States.

## 🚀 Purpose
This dashboard is intended to help stakeholders:
* Identify top-performing product lines and retail channels.
* Track growth trends between fiscal periods.
* Understand the geographic distribution of sales to optimize supply chain and marketing efforts.
